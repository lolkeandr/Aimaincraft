# Create Guide — ИИ-помощник для Create и Create Aeronautics

Мод для **NeoForge 1.21.1**, только клиент (для одиночной игры). Нажимаешь горячую клавишу (по умолчанию **K**) и задаёшь вопрос в окне.

## Что умеет

- При открытии окна **автоматически делает скриншот** игры и отправляет его нейросети вместе с вопросом.
- Знает, что у тебя **в руке и в инвентаре**, на какой **блок ты смотришь** (с его данными NBT, где у Create бывают скорость и нагрузка), и какие моды по теме установлены.
- Берёт **реальные рецепты из твоей сборки** (в том числе Create и Aeronautics, включая жидкости, нагрев и шансы) и показывает их **наглядно, с иконками предметов**.
- **Помнит диалог** между запусками игры (файл `config/createguide-history.json`).

## Как получить готовый jar (без установки Java и Gradle)

1. Зарегистрируйся на github.com и создай новый репозиторий (можно приватный).
2. Загрузи в него **всё содержимое этой папки**, включая скрытую папку `.github`
   (кнопка *Add file → Upload files*, перетащи файлы и папки).
   Если папка `.github` не загрузилась, нажми *Add file → Create new file*, в имени файла напиши
   `.github/workflows/build.yml` и вставь содержимое файла из архива.
3. Открой вкладку **Actions**. Если GitHub просит, нажми кнопку включения workflow.
   Сборка **Build mod** стартует сама после загрузки файлов (3–6 минут).
4. Когда появится зелёная галочка, открой этот запуск, внизу в блоке **Artifacts** скачай `createguide-jar`.
   Внутри zip лежит `createguide-1.0.0.jar`.
5. Положи jar в папку `mods` своей сборки.

Если сборка упала (красный крестик), открой запуск, скопируй текст ошибки и пришли его в чат, я поправлю код.

## API-ключ

Подписка Claude и API оплачиваются отдельно. Нужен аккаунт на сайте разработчиков Anthropic (Claude Platform), пополненный баланс и созданный API-ключ.
В игре нажми **K**, вставь ключ в поле ввода и нажми Enter, он сохранится в `config/createguide-client.toml`.

## Настройки (config/createguide-client.toml)

- `model` — `claude-sonnet-5-5` (по умолчанию, качество) или `claude-haiku-5-5` (дешевле и быстрее).
- `provider` = `openai` — для OpenAI и совместимых сервисов (OpenRouter и др.); тогда поменяй `model` (модель должна понимать изображения) и при необходимости `apiUrl`.
- `sendScreenshot`, `screenshotWidth` — скриншот и его размер (меньше = дешевле).
- `pauseGame` — ставить игру на паузу при открытом окне.
- `extraPrompt` — свои инструкции помощнику.

Горячую клавишу можно сменить в *Настройки → Управление → Create Guide*.

## Ограничения первой версии

- Рецепты, где предмет задан тегом (например «любой слиток железа»), по запросу «где используется» могут не находиться.
- Карточки рецептов не сохраняются в истории (сохраняется только текст).
- Код написан без возможности скомпилировать его при разработке, поэтому первая сборка может потребовать правок.
